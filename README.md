
# AI Text Detection using BERT

## Overview

This project focuses on detecting whether a given text is generated by AI models or written by humans. Using BERT (Bidirectional Encoder Representations from Transformers), a state-of-the-art NLP model, we fine-tune it for binary text classification. The classification task involves differentiating between AI-generated text and human-written content.

## Project Structure

- **Notebook:** `ai-text-detection-BERT.ipynb` contains all the code for preprocessing, model training, evaluation, and inference.
- **Dataset:** Preprocessed datasets with labeled data for AI-generated and human-written text.
- **Model:** A fine-tuned BERT model trained on the dataset for the text classification task.

## Approach and Methodology

### 1. Problem Understanding

The goal of the project is to classify text as AI-generated or human-written. This involves:
- **Binary Classification Task:** AI-generated (class 0) or Human-written (class 1).

### 2. Dataset Preparation

The dataset contains labeled text samples, where each entry is identified as AI-generated or human-written. Here's an overview of the steps involved:

- **Data Sources:**
  The dataset is obtained from multiple sources that include AI-generated text from various models and human-written content.
  
- **Text Cleaning and Preprocessing:**
  - Remove unnecessary characters, punctuations, and special symbols.
  - Tokenize the text using BERT's tokenizer, which converts words into a sequence of integers that BERT understands.
  - Add padding to ensure uniform input size for the BERT model.
  
  Example of Tokenization:
  ```python
  from transformers import BertTokenizer

  tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
  inputs = tokenizer(text, return_tensors='pt', max_length=512, truncation=True, padding='max_length')
  ```

### 3. Model: Fine-Tuning BERT

- **Model Architecture:**
  We use the pre-trained BERT model (`bert-base-uncased`) and fine-tune it for our classification task.
  
  The architecture consists of:
  - BERT layers that generate contextualized word embeddings.
  - A classification layer (fully connected) on top that outputs probabilities for each class (AI-generated or human-written).

- **Fine-Tuning:**
  Fine-tuning involves training the entire model (including BERT layers) on the specific dataset. This enables BERT to learn the nuances between AI-generated and human-written text.
  
  Code example for loading the BERT model:
  ```python
  from transformers import BertForSequenceClassification

  model = BertForSequenceClassification.from_pretrained('bert-base-uncased', num_labels=2)
  ```

### 4. Training

- **Loss Function:** We use cross-entropy loss, commonly used for classification tasks.
- **Optimizer:** AdamW optimizer, which is well-suited for fine-tuning transformer models like BERT.
- **Learning Rate Scheduler:** A linear learning rate scheduler with warm-up is used to gradually increase the learning rate and then decrease it.

  Example of training configuration:
  ```python
  from transformers import AdamW, get_linear_schedule_with_warmup

  optimizer = AdamW(model.parameters(), lr=2e-5, eps=1e-8)
  total_steps = len(train_dataloader) * epochs
  scheduler = get_linear_schedule_with_warmup(optimizer, num_warmup_steps=0, num_training_steps=total_steps)
  ```

- **Epochs and Batch Size:**
  We train the model for several epochs with a suitable batch size to prevent overfitting while ensuring generalization.

### 5. Evaluation

- **Accuracy:** The primary metric used to evaluate the model's performance.
- **Confusion Matrix:** A confusion matrix is used to visualize the performance of the model across the two classes.
- **Precision, Recall, and F1 Score:** These metrics are also used to understand how well the model handles imbalanced datasets and performs in real-world scenarios.

Example of model evaluation:
```python
from sklearn.metrics import classification_report

# Generate predictions
predictions = model(inputs)

# Evaluate
print(classification_report(true_labels, predictions))
```

### 6. Inference

After training, the model is used to classify new text data. The user can input a text, and the model will predict whether it was AI-generated or written by a human.

```python
def predict(text):
    inputs = tokenizer(text, return_tensors='pt', max_length=512, truncation=True, padding='max_length')
    outputs = model(**inputs)
    return torch.argmax(outputs.logits).item()
```

### 7. Results

The fine-tuned model achieved an accuracy of **96.72%** on the validation set. The model demonstrates strong performance, especially in detecting more complex AI-generated texts from GPT models.

- **Confusion Matrix and Error Analysis:** Detailed analysis is performed to identify areas where the model struggles (e.g., complex human-written texts vs simple AI-generated texts).
